### **📱 Tentang Qyo Soundboard**
Bosen soundboard lain gak bisa floating window di HP kentang?  
**Qyo Soundboard** hadir buat ngatasin itu. Udah diotak-atik biar jendela mengambangnya work di semua HP, mau support atau enggak 😎

Kosongin isi? Iya. Biar lu bebas isi sendiri meme, sound, dan vibe lu sendiri.

### **✨ Fitur Unggulan**
- **🪟 Floating Window Universal**: Bisa jendela mengambang di semua HP. Gas sambil main game/scroll
- **🎵 Add Sound Sendiri**: Download kosong. Tinggal masukin file .mp3 lu. Nama otomatis keisi dari nama file, bisa diedit juga
- **🖼️ Sticker/Thumbnail Meme**: Ganti gambar tiap sound jadi meme biar makin kocak
- **⚡ Combo Mode**: Set combo di settings. Pencet sound yang sering lu pake bisa langsung ke-trigger
- **🎨 Color Picker Theme**: Atur tema apk sesuka hati. Tinggal drag hue, saturation, tinggal jadi
- **🔊 Volume Slider**: Atur gede kecil volume soundboard langsung dari app
- **ℹ️ Tab Support**: Ada halaman tentang aplikasi + dukungan via Saweria

### **🚀 Cara Pakai**
1.  Install APK
2.  Buka app > Tambah Sound > Pilih file .mp3
3.  Edit nama & thumbnail meme nya
4.  Aktifin Floating Window dari settings
5.  Gas spam sound nya wkwk
